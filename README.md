# GGIS 407 – Exam 1 Data

Data files for Exam 1 of GGIS 407 (University of Illinois Urbana-Champaign).
Open on the [I-GUIDE JupyterHub](https://jupyter.i-guide.io) with the `iguide` kernel, and create your exam notebook
inside this `ggis407-exam1` folder.

## Data

- `data/us-states-covid.csv`: cumulative COVID-19 cases and deaths by state and territory as of March 23, 2023, from
  [The New York Times](https://github.com/nytimes/covid-19-data) (non-commercial use with attribution).
- `data/us-states-population.csv`: state population (50 states, District of Columbia and Puerto Rico), U.S. Census Bureau
  2018 population estimates, as compiled by the [COVID Tracking Project](https://github.com/COVID19Tracking/associated-data).
- `data/us-states.json`: U.S. state boundaries, from the [folium](https://github.com/python-visualization/folium) example data.
- `data/us_county.zip`: U.S. county boundaries (zipped shapefile), from the U.S. Census Bureau 2023 cartographic boundary file
  `cb_2023_us_county_20m`, with the columns STATEFP, COUNTYFP, GEOID, NAME, STATE_NAME, ALAND and AWATER (areas in m²).
- `data/CDL_2024_Champaign.tif`: USDA NASS Cropland Data Layer 2024, Champaign County, IL (from
  [CropScape](https://nassgeodata.gmu.edu/CropScape/)), the same raster used in Lab 3.
